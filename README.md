# Lifegiver

A Max for Live audio effect for Live 11 (Max 8): it listens to a sound, reads what it is, and helps shape it for the job you give it in the mix. An assistant, not an autopilot.

- `devices/lifegiver/HANDOFF.md`: current state and next step. Start here.
- `devices/lifegiver/DESIGN.md`: the full design (controls, how it decides, tools and methods).
- `devices/lifegiver/BUILD_PLAN.md`: the order of work, phase by phase.
- `devices/lifegiver/RESEARCH.md`: the theory the design must respect, with sources.
- `CONVENTIONS.md`, `HANDOFF_GUIDELINES.md`: shared rules and how handoffs are kept.
